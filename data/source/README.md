# data/source/

Put the NSE price files from Mendeley Data here. `uv run nsefc run` reads every `.csv` and
`.zip` file in this folder and its sub-folders, whatever their layout.

The files are not in the repository. The results published in this repository were computed
from the Mendeley files placed in this folder; to reproduce them, download the same files from
Mendeley Data yourself. [data/README.md](../README.md) lists the collections, the file names
and their checksums.
